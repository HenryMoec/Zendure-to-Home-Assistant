# Zendure to Home Assistant (lokal)

Home-Assistant-Integration für Zendure SolarFlow-Geräte über die lokale REST-API (zenSDK).

- Geräte, Akku-Packs, Sensoren und Regler (outputLimit, inputLimit, socSet, minSoc, acMode, smartMode)
- Einrichtung per IP oder automatische Erkennung über mDNS

## Installation (HACS)
HACS → ⋮ → Benutzerdefinierte Repositories → Repository-URL, Kategorie *Integration* → herunterladen → Home Assistant neu starten.
